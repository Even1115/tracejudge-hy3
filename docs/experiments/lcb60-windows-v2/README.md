- 主报告、逐题状态表以及审计 JSON 只包含统计、公开题号、状态、版本身份和运行元数据。

- 报告中的本机链接已转换为本目录内相对链接；运行身份中的绝对路径作为历史元数据保留。
- 原始报告和原始实验结果保持不变。源代码的两处修复及对应测试在仓库源文件中管理，不能用当前主分支状态替代报告记录的冻结源码身份。
