# 阶段四 P1 第二标注者安排 v1

状态：伦理已批准，冻结协议；待单次交付记录就绪后执行 / 2026-09-02

本安排用于 TraceJudge-Hy3 阶段四 P1 的第二标注者独立复标。目标是对预先冻结的 20 条子集计算 raw agreement、混淆计数及适用时的 Cohen’s κ；不修改或覆盖阶段三的 57 条主标注、方法预测或正式结果。

## 1. 启动条件

指导老师已于 2026-09-02 确认本次第二标注为“已批准”，书面记录保存在私有受限位置，参与同意及数据管理要求已落实；本协议据此将伦理状态记为 `READY`。该状态只表示伦理门已通过，不等于已经完成单次交付记录，也不自动授权发包或收集答案。

在单次交付记录全部填写、双方确认且协调者书面解除操作门之前，不得：

- 正式招募或要求对方承诺参与；
- 发送练习或正式标注包；
- 收集、评分或保存对方的练习/正式答案。

发包前还必须完成一份双方可查的单次交付记录，逐项记录参与同意、化名标注者 ID、实际交付/密码/回传/答疑渠道、收件时间、练习与正式截止时间、报酬或致谢安排、退出截止点和协调者联系方式。任一项缺失都表示不得发包。

## 2. 工作范围与时间

完整流程为：阅读本安排与阶段三标注指南 → 独立完成 5 条 cohort 外公开 Fixture 练习 → 回传练习答案 → 协调者复核规则理解 → 书面通知是否准入 → 通过后独立完成冻结的 20 条正式复标 → 回传与哈希核验 → 书面冻结前不讨论分歧。

计划工作量：

- 阅读指南与本地准备：约 30–60 分钟；
- 5 条练习、自检与必要答疑：约 1–2 小时；
- 20 条正式复标：每条约 15–25 分钟，共约 5–8.5 小时；
- 总计预估 6–10 小时。练习的实际计时将被记录，必要时调整正式期限，但不改变样本或准入规则。

默认相对期限为：练习答案在确认收件后 3 个日历日内回传；协调者在 2 个工作日内反馈；正式 20 条在书面准入与确认收件后 10 个日历日内回传。等待协调者回复超过 24 小时的时段不计入截止期，按实际等待时长顺延。标注者可提前请假或申请延期，不影响自愿参与权利。

## 3. 练习准入与停止规则

练习包固定为 5 条全新公开自建 Fixture，不属于阶段三 57 条 cohort，不包含 HumanEval+、EvalPlus raw、Provider raw、方法预测或任何真实参与者标签。练习参考答案是公开 Fixture 的协调者参考，不是研究结果；它只保存在 Git-ignored、权限受限的协调者目录中，公开 manifest 只记录无答案的逻辑 artifact ID、存储类别和 SHA256，不记录私有路径或正文，在练习答案回传前不得查阅或分发。

准入同时要求：

1. 5/5 条均通过 Schema、必填字段和内部一致性校验；
2. 无隐私、泄露、独立性或盲法违规；
3. `has_error` 与协调者参考至少 4/5 一致；
4. `process_correct` 与协调者参考至少 4/5 一致；
5. 在参考答案判定为有错的 3 条中，`first_faulty_layer` 至少 2/3 一致；
6. 每条 `rationale` 只引用包内公开材料，不构造或要求隐藏输入；
7. 所有分歧完成基于规则的复核后，由协调者书面确认规则理解到位。

最多进行两轮校准：首轮练习与答疑，未通过时可再进行一轮等价规则复核/重做。第二轮后仍未满足全部条件，或任一轮发生不可恢复的盲法/隐私违规，则停止本次合作，不发送正式包。练习分数只用于规则校准，不作为研究终点或对个人能力的普遍评价。

## 4. 盲法、独立性与允许的辅助

标注者必须独立阅读和判断，在正式冻结前不得：

- 查看主标注、其他标注者答案、五种方法预测或分歧汇总；
- 不得主动检索或查阅 TraceJudge-Hy3 代码仓库、报告、Release、图表或已发布结果；公开页面不含私有逐轨迹主标签，但其聚合结果和项目上下文仍可能造成先验污染；
- 不得与任何人讨论条目内容、个别判断或疑似答案；
- 使用生成式 AI、外部 LLM、搜索引擎、在线 IDE、在线执行服务、代码分析网站或题解；
- 执行、修改、调试或向第三方上传包内代码。

允许使用本地纯文本阅读器、本地 JSON 格式检查和协调者提供的离线校验命令；这些工具不得联网、推断标签或展示参考答案。如规则不清，只能向协调者询问规则；不得在问题中复制完整代码或可识别的隐私内容，仅引用盲化 `item_id` 和字段名。

## 5. 接收、核验、存储和回传

电子交付只允许使用 AES-256 或强度不低于 AES-256 的加密归档。归档文件通过单次交付记录中明确的、已身份验证的一对一文件通道传送；解密密码只能通过实时语音电话或当面单独交付，不得与归档使用同一文本渠道。移动存储介质面交时也必须使用加密归档。未经项目负责人单次明确授权，不得上传任何标注包或成果。

收件后，在打开归档前核对协调者提供的 SHA256：

```text
macOS:             shasum -a 256 <file>
Linux:             sha256sum <file>
Windows PowerShell: Get-FileHash -Algorithm SHA256 <file>
Windows cmd:       certutil -hashfile <file> SHA256
```

哈希不一致时不得打开，立即按第 6 节停止并报告。

解压后材料只能保存在标注者个人电脑上一个专用的本地文件夹中，该磁盘须启用系统全盘加密或等价保护。不得放入 iCloud、OneDrive、Dropbox、网盘、邮箱草稿、Git 仓库、自动备份目录、聊天工具文件区或任何会同步/上传的位置。不得创建未加密副本、截图、打印件或贴进其他笔记系统。

成果回传使用单次交付记录中的回传通道，同样使用独立密码的加密归档；协调者回传接收文件 SHA256，双方确认一致。答疑仅使用记录中的一对一身份验证文本渠道，不接受群聊、公开 Issue 或临时未记录渠道。

## 6. 泄露、误传与异常处理

一旦发现或怀疑哈希不符、解密失败、材料误传、自动同步、未授权访问、看到主标签/方法预测、意外查到本项目结果或其他可能污染，标注者必须：

1. **立即停止标注**；
2. 保留现场，不再打开涉事归档、条目或结果；
3. 不自行删除、转移、重新下载、补做或继续标注；
4. 第一时间通过记录的紧急联系方式报告事实、发现时间和已知影响范围，不在报告中复制敏感正文；
5. 等待协调者书面决定是否恢复、更换包、剔除受影响条目或终止合作。

协调者必须记录事件及处置，不得在不披露的情况下将受污染结果作为独立复标。

## 7. 自愿退出、删除与保密

标注者可随时退出，无需解释原因。在协调者发出“正式标签集已冻结”的书面通知前退出，已回传的部分标签不纳入分析，协调者删除该答案和身份连接；标注者按下述步骤删除全部材料。冻结通知发出后，标签已去识别并纳入聚合，不能保证从已生成的聚合结果中单独撤回；这一截止点必须在参与同意中再次明确。

协调者确认完整收件或确认退出后 24 小时内，标注者必须删除归档、解压目录、临时文件和本地回收站中的相关材料，然后只回传“已删除”确认，不回传屏幕截图。

在 P1 聚合结果公开发布前，不得对外讨论研究条目、个别判断、分歧或进度。无论聚合结果是否发布，私有逐条材料、隐藏评测内容、身份映射、其他人的标签和未脱敏理由均持续保密。

## 8. 正式子集与分歧处理边界

正式复标子集已在查看第二标注者练习答案之前，以 `phase4_p1_formal_subset_v1` 从 57 条主标注 cohort 中确定性冻结 20 条：15 条自然轨迹和 5 条反事实轨迹，反事实覆盖全部 3 个父题且每个父题最多 2 条。抽样未使用主标签、方法预测、Provider 状态或事后结果分层；私有 manifest 保存在 Git-ignored 受限目录，公开承诺只披露计数、规则和哈希，不披露入选 trace ID。该冻结不生成正式标注包，也不授权发包或收集答案。

只有完整收件、Schema 验证、哈希冻结和原始一致性统计都完成后，才能打开分歧讨论。讨论后任何裁决只能写入新的裁决产物，不得回写主标注或第二标注者原始标签。Cohen’s κ 仅在两个类别均出现且期望一致率可定义时报告；否则报告 raw agreement、混淆计数和κ不适用原因。

## 9. 单次交付记录的必填项

单次交付记录不进入公开 Git、Release 或报告，由协调者在受限目录保存。必须完整记录：

- 协议 ID 与精确 SHA256；
- 伦理状态、核实者与核实时间；
- 伦理认定为“已批准”、确认日期 2026-09-02，以及书面记录保存在私有受限位置；
- 参与同意方式与时间；
- 化名标注者 ID，不写入对外报告；
- 实际一对一交付、密码、回传、FAQ 和紧急联系渠道；
- 收件时间、练习截止时间、正式截止时间和已批准延期；
- 报酬、结算、致谢与署名边界；本协议不自动承诺金钱、署名或其他利益；
- 退出截止点、数据保留期和预定销毁日期；
- 发包归档 SHA256、回传归档 SHA256、异常记录和最终删除确认。

本协议不是参与同意书、伦理批件或雇佣合同；相关法律/机构文件必须在适用时另行完成。
